# Shanti Katua — Junior Data Analyst Portfolio

Responsive static portfolio for Shanti Katua.

## Pages
- `index.html` — Home and overview
- `about.html` — Background, academic direction and working principles
- `skills.html` — Python, Pandas, Excel, SQL, Power BI and analytical workflow
- `projects.html` — Clearly labelled spaces for genuine project case studies
- `services.html` — Entry-level analytical capabilities and possible deliverables
- `contact.html` — Email, phone, LinkedIn and contact form

## Run locally
Open `index.html` in a browser. No build step is required.

## Update the portrait
Replace `assets/images/shanti-katua.jpg`, keeping the same filename.

## Add projects
Edit `projects.html` and the featured project cards in `index.html`. For each genuine project, include its question, dataset context, preparation and analysis steps, tools actually used, verified findings and any repository/report link. The current project spaces are placeholders, not claims of completed work.

## Contact form
The form validates its fields and opens the visitor’s default email application with a prefilled message to `katuashanti@gmail.com`. It does not send or store messages through a server.
